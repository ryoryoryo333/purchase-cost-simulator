# 購買コスト削減シミュレーター

複数商品の切り替え前後の年間費用、年間削減効果、初期費用の回収期間を試算するブラウザアプリです。

## 主な機能
- 商品を複数登録して一括比較
- 切り替え元・切り替え先のメーカー、商品名、年間数量、単価を入力
- 商品別・全体共通の初期費用を集計
- 年間・月間削減効果、削減率、回収月数・日数を自動計算
- 5年間の累積純削減額グラフ
- 1年・3年・5年の効果比較
- ブラウザ内への案件保存、JSONバックアップ・復元
- Excelで開けるCSV出力、印刷・PDF保存
- 商品画像URL登録と画像検索へのリンク

## 計算上の前提
- 年間費用 = 年間数量 × 単価
- 年間削減効果 = 切り替え元年間費用合計 − 切り替え先年間費用合計
- 月間削減効果 = 年間削減効果 ÷ 12
- 回収月数 = 初期費用総額 ÷ 月間削減効果（年間削減効果が正の場合）
- 回収日数 = 初期費用総額 ÷ (年間削減効果 ÷ 365.25)
- 累積純削減額 = 年間削減効果 × 経過年数 − 初期費用総額

数量・単価が一定で推移する単純試算です。消費税、値上げ、保管費、廃棄費、品質差、切り替え後の運用コストなどは別途考慮してください。

## データとプライバシー
入力データは利用中のブラウザの localStorage に保存され、サーバーには送信されません。ブラウザのデータ削除や端末変更に備え、JSONバックアップを利用してください。GitHub Pagesで公開するサイト自体はインターネット上で誰でも閲覧できます。機密情報や個人情報を入力しないでください。
